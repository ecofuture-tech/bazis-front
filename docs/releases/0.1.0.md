# bazis-front 0.1.0

The first release of the frontend layer of Bazis. It requires `bazis>=2.16.0`.

## What it is

A Python package (`pip install bazis-front`, module `bazis.contrib.front`) with the
frontend of a product built on Bazis: React, TypeScript, Vite, TanStack Query and
Tailwind with shadcn/ui. The TypeScript code is not published to npm: it is shipped in the
wheel as package data and copied into the frontend of the product, which owns the copy and
gets fixes through `bazis_front update`.

## What it contains

- `assets/client`: the JSON:API protocol of Bazis in TypeScript, typed by the OpenAPI types
  generated from the product.
- `assets/react`: hooks over the client and TanStack Query for lists, items, runtime
  schemas, mutations, forms, the transits of bazis-statusy, the uploads of bazis-uploadable,
  the socket of bazis-ws, the tasks of bazis-bg and the requests of bazis-async-request.
- `assets/ui`: components on shadcn/ui, each with its contract test.
- `assets/template`: the frontend of a product.
- `assets/playwright`: helpers that run the steps of the scenarios through the `data-bz`
  marks of the screens.
- The commands `manage.py bazis_front init`, `contract`, `check`, `add`, `e2e` and `update`.
- The guide for the agents that build a product: `bazis/contrib/front/AGENTS.md`, read
  through the tools of bazis-mcp.

## Notes

- The API may change in the minor versions while the project is below 1.0.
- The template pins one version of Vite for the whole dependency tree (`overrides`), since
  npm 10 fails to install a Vite 8 together with Vitest otherwise.
