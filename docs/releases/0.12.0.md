# bazis-front 0.12.0

The look of a product from its specs and its theme only: the fonts served by the frontend
itself, the cards of a list, the summary of a card, the brand and the sidebar on their own
tokens, the money and the dates in the language of the product, and a filter of a tile by a
set of values and by a negation. It requires `bazis>=2.17.0`, as 0.11 did; the format of the
contract stays 12.

## Added

- The codes of the new checks: S064 (the cards of a list), S065 (the summary of a card), S066
  (a field both in the summary of a card and in a section of it), D014 (the heading font
  without its `opsz` axis), D015 (the `subsets` of a font without a language or a currency
  sign of the product), D016 (a `<Family> Fallback` in a stack that the generator does not
  make), D017 (`brand.image` that is not a file in `frontend/public/`).

## Changed

- S014 also covers the filter of the last items of a dashboard and each value of a set and of a
  negation; a lookup takes one value. S020 also covers `fraction` and `per` without `currency`.

## Upgrading

```bash
pip install -U bazis-front
python manage.py bazis_front update      # the client, the hooks, the components, the schemas of the specs
python manage.py bazis_front check
python manage.py bazis_front design
python manage.py bazis_front screens
python manage.py bazis_front e2e
```
