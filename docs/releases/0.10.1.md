# bazis-front 0.10.1

A patch of 0.10.0, from a run of an agent that built a product in Russian with bazis-authing:
a test of the template that failed in that language, the name of a file too small to touch on
a phone, and the hints of three errors of the specs that named only the schema to follow. It
requires `bazis>=2.17.0`, as 0.10.0 did; the format of the contract stays 11.

## Fixed

- **The tests of the login in a window of the template pass in every language.**
  `src/app/session.test.ts` expected the English errors `The login has expired` and
  `blocked the window`, while `loginInWindow` throws `t('login.expired')` and
  `t('login.blocked')` in the language of the product: with bazis-authing (its section in the
  contract runs these tests) and Russian as the language, `npm test` failed twice. The test
  expects the texts of the same keys, `t` of `@/app/language`; it still fails when
  `loginInWindow` throws another error.
- **The name of a file is 44 px high and wide on a touch screen.** The button of `FileView`
  (`resource`: the file of a card, a cell or a field, which downloads it) was the height of its
  line, 24 px, and `bazis_front shots` warned of it on a phone (V009) on every screen that shows
  a file. On a touch screen (`pointer-coarse:`) it is now 44 px at least, as the other targets
  of a finger of the components; for a mouse it does not change. The warning stays for the
  small controls of the product.

## Changed

- **The hints of three errors of the specs say what to write.** P002 of a `title` of a role
  given in the languages (`title: {ru: Диспетчер}`): the title of a role is one text that names
  it for the readers of the specs, never shown by the frontend (its schema says so too). S002 of
  `requires` in a create form of a dashboard: the button of the form is shown to the users who
  may add the entity, so the key goes. S006 of a tile that opens a screen that is not a list (a
  board, a calendar): a tile opens a list of its entity with the `filter` of the tile, or nothing;
  a board or a calendar is reached from the navigation. The other S006 keep their hints. The
  hints of `created` and `saved` (0.10.0) are given the same way: for the key in the body of a
  step (`submit: {saved: true}`) and for the key next to the step (`- submit: {}` and
  `saved: true` at the indent of `submit`); unlike 0.10.0, not for a key deeper in the step.
- The guide: V009 of a control of a component of bazis-front is its defect, reported, not fixed
  in the copies.

## Upgrading

```bash
pip install -U bazis-front
python manage.py bazis_front update      # src/app/session.test.ts of the template, resource, the schemas of the specs
python manage.py bazis_front shots       # V009 of the names of the files gone
```

A product that left `src/app/session.test.ts` as the template wrote it gets the new test from
`update`. One that changed it (the texts of its language written in the test) gets the change
merged, or a conflict that `update` names with the file of bazis-front: take that file whole,
the test of the template no longer needs a change for a language.
